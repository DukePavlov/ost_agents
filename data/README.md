# Dataset directory

Run `python download_data.py` from the repository root. It fetches the **Breast Cancer Coimbra** dataset (UCI dataset ID 451) and creates `data/dataR2.csv`.

Alternatively download **dataR2.csv** from https://archive.ics.uci.edu/dataset/451/breast+cancer+coimbra and place it in this directory.

**Attribution:** Patricio, M. et al. (2018). *Breast Cancer Coimbra* [Dataset]. UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C52P59. License: CC BY 4.0 https://creativecommons.org/licenses/by/4.0/

Classification = 1 for healthy controls; Classification = 2 for breast cancer patients.
